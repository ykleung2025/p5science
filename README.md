# 小小科學家探究助手：空氣的秘密

小學五年級科學探究對話。學生圍繞「杯子＋紙巾」實驗，一步步觀察、提出證據、解釋，並自己說出結論：**空氣佔有空間**。

網上版本：<https://ykleung2025.github.io/p5science/>

介面語文是繁體中文（`zh-HK`）。

## 課堂上怎樣用

1. 先做實驗：杯底塞紙巾，杯口朝下垂直壓入水中，再把杯子傾斜。
2. 打開上面的網頁。畫面有杯子和紙巾的實驗動畫，會跟著正確答案走到下一步；答錯時動畫保持原位。可以點快捷答案，也可以自己打字。
3. 按 **Enter** 或「傳送」。使用中文輸入法選字時，不會把候選字誤送出去。
4. 「提示」只給提醒，複製整句提示不會當正確答案。
5. 「聽聲音」用瀏覽器語音，優先選擇粵語（`zh-HK` 或 `yue`）。
6. 「重新開始」要再按一次確認，避免誤按清掉進度。

## 檔案

- `index.html`：頁面
- `css/style.css`：樣式
- `js/grade.js`：答案判斷與粵語語音選擇
- `js/app.js`：對話、鍵盤與朗讀

樣式與程式以 `?v=3` 連結，避免瀏覽器沿用舊檔。實驗動畫是頁面裡的 CSS，不另載圖片或 CDN。頁面不再依賴 Tailwind CDN 或 Google Fonts，校園網絡擋外部 CDN 時仍可開啟。字型使用裝置上的蘋方、思源黑體或微軟正黑體。
